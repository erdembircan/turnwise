# Turnwise

Built static site for [Turnwise](https://erdembircan.github.io/turnwise/), a camera-based Rubik's cube solver.

This repository holds published output only. Every merge to `main` in the private source repo rebuilds the site and force-pushes `dist/` here through a GitHub Actions workflow.

Do not open pull requests or push commits against this repository — anything committed here is overwritten on the next deploy. Report issues or propose changes against the source instead.
